# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-05-18

Initial public release of `psa-parser`.

- Provides a C parser library for PSA planogram files with streaming callbacks.
- Includes JSON helper APIs and document-oriented parse helpers.
- Ships a CLI supporting document output, NDJSON streaming, and summary mode.
- Includes test coverage for numeric parsing, preprocessing, JSON encoding, and sample parsing.
- Adds integration guidance for foreign-language bindings via `docs/bindings.md`.
