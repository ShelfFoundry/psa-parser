# Divider Record (`Divider`)

## Shape

- Indicator: column `0` = `Divider`.
- Parsed columns: `0..17`.

## Column mapping

- `0`: record type text (string; expected `Divider`)
- `1`: divider id text (string)
- `2`: x position (double)
- `3`: width (double)
- `4`: y position (double)
- `5`: height (double)
- `6`: z position (double)
- `7`: depth (double)
- `8`: color code (int)
- `9`: undefined text slot 1 (string)
- `10`: description text slot 1 (string)
- `11`: description text slot 2 (string)
- `12`: description text slot 3 (string)
- `13`: numeric slot 1 (double)
- `14`: numeric slot 2 (double)
- `15`: numeric slot 3 (double)
- `16`: undefined text slot 2 (string)
- `17`: undefined text slot 3 (string)
